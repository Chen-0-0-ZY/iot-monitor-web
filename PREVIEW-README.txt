# 温湿度监控应用 - 本地预览说明

## 启动服务器

服务器已经在后台运行！

## 访问应用

请在浏览器中手动打开以下地址：

**简化版（推荐首次测试）：**
- http://localhost:5000/

**完整版（带有PWA功能）：**
- http://localhost:3000/iot-monitor-web/

## 故障排查

如果页面显示空白，请按以下步骤检查：

1. **打开浏览器开发者工具**
   - 按 F12 键
   - 切换到 Console（控制台）标签
   - 查看是否有红色错误信息

2. **检查Network（网络）标签**
   - 查看资源是否加载成功（200状态码）
   - 查看是否有404错误

3. **常见问题**
   - 如果看到 "Failed to load resource" 错误，说明资源路径有问题
   - 如果控制台有 JavaScript 错误，请记录错误信息
   - 如果页面完全空白，可能是JavaScript执行出错

## 数据说明

应用需要以下配置才能正常显示数据：
1. 阿里云IoT AccessKey
2. 阿里云IoT AccessSecret  
3. ProductKey
4. DeviceName
5. 区域设置

请在应用的"设置"页面配置这些信息。

## 趋势图说明

趋势图会显示历史数据，需要先在本地存储中有数据才能显示。
数据可以通过以下方式获取：
- 在设置页面点击"获取数据"按钮
- 系统会自动定时获取最新数据
